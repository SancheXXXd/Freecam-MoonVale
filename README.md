# Freecam (MoonVale)

A fork of [Freecam](https://modrinth.com/mod/freecam) for the MoonVale server.

## What was completely deleted?
- Flying through the blocks
- Interacting with the world through freecam
- Freezing the player while in freecam
- Plasmo Voice spying through a freecam
- Going to unloaded chunks
- Modifying the environment through freecam
- Unlimited Flight (3 chunk limit)
